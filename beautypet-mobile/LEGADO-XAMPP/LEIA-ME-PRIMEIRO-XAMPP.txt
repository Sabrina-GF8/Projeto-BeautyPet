PARA RODAR O MOBILE
-------------------
Abra esta pasta no VS Code e rode:

npm.cmd install
npx.cmd expo start -c

No src/lib/api.ts confira:
    const IP_DO_COMPUTADOR = "192.168.0.178";

Troque apenas se o IPv4 do seu computador for outro.

XAMPP
-----
Copie:
    xampp/beautypet-api

para:
    C:\xampp\htdocs\beautypet-api

Ligue Apache + MySQL.

Teste no PC:
    http://localhost/beautypet-api/api.php?acao=teste_conexao

No celular, trocando pelo IPv4 do PC:
    http://SEU-IP/beautypet-api/api.php?acao=teste_conexao
